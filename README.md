### 简介

******

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) 应用文档, 克隆 (Clone) 自 [hyb1996/AutoJs-Docs](https://github.com/hyb1996/AutoJs-Docs/).

AutoJs-Docs 项目 (称为 "Auto.js 开源文档项目") 由 [hyb1996](https://github.com/hyb1996) 于 `2017/08/21` 初次发布, 于 `2017/09/11` 停止维护, 最终文档名称为 `4.1.0`.

此项目为 "Auto.js 开源文档项目" 的备份项目, 保持原项目文档的结构和内容, 不做任何改动.

******

### 关联项目

******

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) 是 Auto.js 最终开源版本 `4.1.1 Alpha2` 的克隆项目, 用于保留原始源码, 并做必要的更新使其可以正常构建并在新版安卓系统中运行.

AutoJs4 同时是 [AutoJs6](http://project.autojs6.com) 的行为基准: 除少数特定情况外, 能在 AutoJs4 正常运行的脚本, 在 AutoJs6 上也应正常运行且效果与结果完全一致.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) 与 [AutoJs6-Documentation](http://docs-project.autojs6.com) 的关系与此类似, 前者保留 Auto.js `4.1.0` 文档的最终源码, 并作为后者的参考基准.

<summary>Related Projects (English)</summary>

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) is a clone of the final open-source Auto.js release `4.1.1 Alpha2`. It preserves the original source code and receives only the updates needed to keep it buildable and runnable on recent Android versions.

AutoJs4 also serves as the behavioral baseline of [AutoJs6](http://project.autojs6.com): apart from a few specific cases, a script that runs correctly on AutoJs4 should also run correctly on AutoJs6 with exactly the same effect and result.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) and [AutoJs6-Documentation](http://docs-project.autojs6.com) have a similar relationship: the former preserves the final source of the Auto.js `4.1.0` documentation and serves as the reference baseline of the latter.
